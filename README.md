# テロッパ（仮）

ブラウザで使える、YouTube の解説動画・ゲーム実況向けの動画編集ソフトです。しゃべっていない「間」を自動で切る機能と、声を自動で字幕にする機能を中心に、初めての人でも迷わず1本完成できることを目指しています。

- 仕様書：[docs/spec.md](docs/spec.md)
- 現在の版：v1.0.0-rc.2（v1.0 の候補。録画を読み込んでから、YouTube に上げる準備までひととおりできる段階。ライセンスは決めました（下の「ライセンス」）。公開場所は GitHub Pages（`https://anyt1n9.github.io/noname/`）。正式な名前が決まったら v1.0.0 にします。[docs/release.md](docs/release.md)）
- 対応ブラウザ：パソコンの Chrome・Edge の最新版

## 使い方

初めての人は、最初の画面の「**見本の録画で練習する**」がおすすめです。テロッパが作る短い見本の録画（約45秒）で、読み込みから書き出しまでを案内つきで試せます。

1. **読み込み**：「録画を選ぶ」を押すか、録画のファイルを画面に落とします（MP4・MOV・MKV・WebM。何本でも入れられます）。録画はパソコンの中だけで使い、インターネットには送りません。
2. **いらない部分を消す**：画面下のタイムラインの下の段を、消したい範囲だけマウスでなぞり、「消す」を押します。上の名前の帯をドラッグすると、順番を変えられます。まちがえても「元に戻す」（Ctrl+Z）で戻せます。
3. **「間」を切る**：しゃべっていない「間」を自動で見つけ、タイムラインに赤い印で出します。残したい場所は印を押すと残せます。「まとめて切る」で切ります。録画に音が複数入っている（OBS で声とゲームの音を分けて録った）ときは、「音の設定」で「あなたの声」を選ぶと正確になります。「えー」「あのー」のタブでは、口ぐせを切る候補を出します（試験的）。
4. **字幕**：「自動で字幕を作る」を押すと、あなたの声を AI が聞き取って字幕にします（最初の1回だけ、AI の部品をダウンロードします）。字幕の一覧で書き換えたり、分けたり、つないだりできます。行の「はさみ」を押すと、その字幕の部分を動画から消せます（言い間違いを文章を見ながら消せます）。色・大きさ・位置も選べます。YouTube の字幕機能で使えるファイル（.srt）も書き出せます。
5. **飾り**：タブを切り替えて使います。
   - **画像**：タイムラインで範囲をなぞって「画像を置く」を押すと、その間だけ画像を出せます（右上・中央・画面いっぱい など。プレビューの上でドラッグして動かせます）。
   - **矢印・枠**：矢印・四角い枠・丸を置けます。色・太さ・向きを選べます。
   - **拡大**：範囲をなぞって「拡大を入れる」を押し、プレビューの点線の四角を動かすと、そこを大きく見せます。寄るときと戻るときは自動でなめらかに動きます。
   - **速さ**：範囲をなぞって 0.5倍・2倍・4倍 を選びます。速くしても声の高さは変わりません。字幕の時間も自動で合います。
   - **フェード**：場面の変わり目で、画面を一度暗くしてから切り替えます。
6. **音の仕上げ**：
   - **声**：「声の大きさをそろえる」で、YouTube で聞きやすい大きさにします。「雑音を減らす」で、エアコンの音などを小さくできます。大きすぎる音は自動で抑えるので、音が割れません。
   - **BGM**：入っている5曲から選べます（どれもテロッパの中でプログラムで作った曲です）。自分で用意した曲も使えます。しゃべっている間は BGM が自動で小さくなります。
   - **効果音**：「ピコン」「ドン」などの効果音を、再生位置に置けます。
7. **書き出し**：「次へ：書き出し」を押し、画質（きれい・ふつう・軽い）を選んで「書き出す」を押すと、MP4 ファイルとして保存できます。
8. **公開の準備**：タイトル・概要欄・チャプター（目次）の案を AI に作ってもらえます。チャプターは YouTube のルール（0:00 から・3つ以上・それぞれ10秒以上）に合わせて直します。「概要欄をコピー」で、YouTube Studio に貼れます。「サムネイル」では、動画の一場面に大きな文字を載せて、サムネイル画像（PNG・JPEG）を作れます。

**AI のお手伝い**：上の「AIに聞く」で、動画の内容の調べものや台本の下書きを AI に頼めます。AI のサイト（ChatGPT・Claude・Gemini・Microsoft Copilot）を開くだけで、貼り付けて送るのはあなたです（送った文章は、そのサイトの会社に送られます）。新しい Chrome では、パソコンの中で動く AI（Chrome に入っている AI）も使えます。AI の答えは間違えることがあるので、確かめてから使ってください。

テロッパがインターネットに送る情報（どんなときに、どこへ、何を）は、上の「このソフトについて」→「外部に送る情報の一覧」で確かめられます。録画・字幕・編集内容は送りません。

編集の途中経過はブラウザの中に自動で保存されます。別のパソコンに移すときは、上の「保存」で作品ファイル（.teroppa）に保存できます（画像と曲は作品ファイルに入ります。録画のファイルは別に残しておいてください）。

他の人が作った画像や曲を、許可なく動画に使うと著作権の侵害になります。自分で作ったものか、動画に使ってよい条件（ライセンス）を確かめたものだけを使ってください。

| キー | 動き |
|---|---|
| スペース | 再生・一時停止 |
| ← → | 1秒戻る・進む（Shift と一緒に押すと5秒） |
| Delete | なぞった範囲を消す |
| Esc | なぞった範囲をやめる |
| Ctrl + Z / Ctrl + Y | 元に戻す / やり直す |
| Ctrl + S | 作品ファイルに保存 |
| ＋ / − | タイムラインの拡大・縮小 |
| ? | キーの一覧を表示 |

## 自分のパソコンで動かす

[Node.js](https://nodejs.org/)（バージョン22以上）を入れてから、次を実行します。

```bash
npm install
npm run dev
```

表示された URL（例：`http://localhost:5173/`）を Chrome か Edge で開くと使えます。

## 開発用のコマンド

```bash
npm test            # 自動テスト
npm run typecheck   # 型チェック
npm run build       # 公開用ファイルを dist/ に作る
npm run check       # 上の3つをまとめて実行
```
