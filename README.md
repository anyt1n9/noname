# テロッパ（仮）

ブラウザで使える、YouTube の解説動画・ゲーム実況向けの動画編集ソフトです。しゃべっていない「間」を自動で切る機能と、声を自動で字幕にする機能を中心に、初めての人でも迷わず1本完成できることを目指しています。

- 仕様書：[docs/spec.md](docs/spec.md)
- 現在の版：まだコードはありません（仕様を決めている段階）

## 予定している主な機能

- 録画をつなぐ・なぞって消す・書き出す（MP4）
- しゃべっていない「間」を自動で見つけて切る
- 声を自動で字幕にする（パソコンの中で処理し、動画をネットに送りません）
- 字幕の文章を消すと、その部分の動画も消える
- 画像・矢印・拡大・速さの変更、BGM・効果音
- チャプター・タイトル・概要欄の案、サムネイル作成

## ライセンス

ソースコードのライセンスはまだ決めていません。決まるまでは、コードを見ることはできますが、使ったり改造したりすることはできません。
