# テロッパ（仮）仕様書

> 仮の名前。公開前に、特許庁の商標検索（J-PlatPat）と既存のアプリ・サービス名で重複がないか確認する。

この文書は、これまでの相談で決まった内容をまとめたもの。数値（秒数、文字数、画質など）はすべて仮で、実際に使いながら調整する。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 種類 | 動画編集ソフト |
| 主な対象 | YouTube の解説動画・ゲーム実況（横長、1人でしゃべる） |
| 動かす場所 | ブラウザ（Chrome と Edge の最新版）。インストール不要 |
| 読み込む録画の長さ | 3時間まで |
| 書き出す動画 | MP4、横長（16:9）。なめらかさ（1秒あたりのコマ数）は元の録画に合わせる |
| 料金 | 無料。ロゴの透かしも入れない |
| 開発で試すパソコン | 高性能な Windows PC（ゲーム用のグラフィックボードあり） |

### テロッパならではの特徴

1. **しゃべり動画の面倒な作業を自動にする**：「間」を見つけて切る（無音カット）、声を文字にする（自動字幕）。初心者が一番時間を取られる作業を、ボタンひとつにする。
2. **迷わない画面**：次にやることを、いつもひとつだけ大きく案内する。案内どおりに進めれば1本完成する。
3. **動画をネットに送らない**：読み込み・自動字幕・書き出しは、すべて使う人のパソコンの中で行う。
4. **無料・インストール不要・透かしなし**：ブラウザで開くだけで使える。

### 有料ソフトと比べた位置づけ

機能の数では有料ソフトに勝とうとしない。解説・実況で必要な作業に絞り、「速く、迷わずできる」ことで勝つ。

| 機能 | テロッパ |
|---|---|
| 録画をつなぐ・切る | ○（v0.1） |
| 無音カット | ○（v0.2） |
| 自動字幕 | ○（v0.3、無料・パソコンの中で処理） |
| 文章で編集 | ○（v0.4） |
| BGM・効果音（声の間は BGM を自動で小さく） | ○（v0.5） |
| 画面の一部を拡大・速さを変える・矢印や枠 | ○（v0.6） |
| 声の雑音を減らす・音量をそろえる | ○（v0.7） |
| 切り替え効果 | △ フェードだけ |
| 素材集（BGM・テンプレート） | △ 権利を確かめたものだけなので少なめ |
| 色の補正、動きをつけるアニメーション、背景の合成 | ×（解説・実況ではあまり使わず、初心者には難しい） |
| 顔出しの小窓（ワイプ）、縦長ショートへの作り直し | ×（あとで考える） |

## 2. 用語

画面の文言では専門用語を避ける。この表の「画面での言い方」を使う。

| 用語 | 画面での言い方 | 意味 |
|---|---|---|
| プロジェクト | 作品 | 1本の動画を作るための作業のまとまり |
| 録画 | 録画 | 読み込んだ動画ファイル |
| 素材 | 素材 | 録画・画像・BGM・効果音のこと |
| タイムライン | タイムライン | 画面下の横長の帯。動画・字幕・音が時間の順に並ぶ |
| 再生位置 | 再生位置 | いまプレビューに映っている時刻。タイムライン上の縦線 |
| クリップ | （見せない） | タイムラインに並んだ素材のひとかたまり |
| 声の音 | あなたの声 | 録画に入っている音のうち、しゃべっている人の声 |
| 無音カット | 「間」を切る | しゃべっていない部分を見つけて切ること |
| 候補 | 切る候補 | 自動で見つけた「切ったほうがよさそうな場所」。切る前に確かめられる |
| 字幕 | 字幕 | 画面に出す文字（テロップ） |
| テンプレート | 見た目 | 字幕やサムネイルの見た目のひな形 |
| 書き出し | 書き出し | 完成した1本の動画ファイルを作ること |

## 3. 画面

### 3.1 全体の形（案内つきタイムライン）

```
[①読み込み]→[②間カット]→[③字幕]→[④BGM]→[⑤書き出し]   ← 手順の案内
──────────────────────────────────────────
                                      │ 字幕の一覧
        （ 動画のプレビュー ）          │ 0:12 今日はボス戦です
                                      │ 0:15 このボス、実は弱点が…
──────────────────────────────────────────
 「間」を自動で切りました（3分12秒 短くなりました）  ← いまやることの案内
    [ 結果を見る ]        [ 次へ ▶ ]
──────────────────────────────────────────
 動画 ■■■■ ■■■ ■■■■■■ ■■■                          ← タイムライン
 字幕   ▭▭  ▭▭▭   ▭▭  ▭▭▭
 BGM  ━━━━━━━━━━━━━━━━━━
```

- 上の**手順の案内**どおりに進めれば1本完成する。慣れた人は、下のタイムラインで自由に細かく直せる。
- 手順は版が上がるたびに増える。v0.1 は「読み込み → 書き出し」だけ。
- 右側の字幕の一覧は、字幕ができてから出す（v0.3〜）。

### 3.2 迷わない画面の約束

- 次にやることを、いつもひとつだけ大きく見せる。
- 1画面に出すボタンを少なくする。使う場面でだけ出す。
- 専門用語を使わない（「トリミング」ではなく「切る」）。
- 自動でやったことは「提案」として見せ、気に入らなければ1回押すだけで戻せる。
- 「元に戻す」がいつでも使える。失敗を怖がらなくていい。
- ボタンにマウスを乗せると、短い説明と、使えるキーを出す。

### 3.3 見た目

- 暗い画面と明るい画面を切り替えられる。最初はパソコンの設定に合わせる。
- テーマ色は**オレンジ**。明るい画面では、文字が読みにくくならないよう濃いめのオレンジを使う。
- 既存の動画編集ソフトの画面デザイン・アイコン・ロゴはまねしない。

## 4. 編集の流れ

使う人がたどる流れ。すべての版がそろったときの形。

1. **読み込み**：録画を入れる（何本でも）。音が複数入っていたら「どれがあなたの声？」を選ぶ。
2. **「間」を切る**：無音カットの候補を確かめて、まとめて切る。
3. **字幕**：自動で文字起こし。間違いを一覧で直す。見た目を選ぶ。
4. **飾り**：画像・矢印や枠・拡大・速さの変更を入れる（使わなくてもよい）。
5. **BGM・効果音**：曲を選ぶと、声の間は自動で小さくなる。
6. **書き出し**：画質を選んで MP4 にする。字幕は .srt ファイルでも出せる。
7. **仕上げのお手伝い**：チャプター・タイトル・概要欄の案、サムネイル。

---

## 5. 読み込み

- 読み込める形式：MP4、MOV（iPhone など）、MKV（OBS でよく使う形式）、WebM。
- iPhone の新しい形式（HEVC）は、パソコンによっては読めないことがある。そのときは理由と対処を画面で案内する。
- 複数の録画を読み込むと、読み込んだ順にタイムラインに並ぶ。ドラッグで並べ替えられる。
- 元の録画ファイルは書き換えない。編集内容は「どの録画の、どこからどこまでを使うか」の記録として持つ。
- 録画を丸ごとメモリに読み込まず、必要な部分だけを読む。3時間の録画でも重くならないようにする。

### 5.1 声を選ぶ（v0.2）

- OBS などでは「自分の声」と「ゲームの音」を別々の音として1つのファイルに保存できる。
- 録画に音が複数入っていたら、読み込んだときに聴き比べて「あなたの声」を選んでもらう。
- 無音カットと自動字幕は、選んだ声の音だけを使う（ゲームの音にじゃまされず正確になる）。
- 声とゲームの音は、別々に音量を変えられる。
- 音がひとつしかない録画は、そのまま使う。
- OBS で声とゲームの音を分けて録る設定方法を、手順の案内として載せる（OBS 自体はソフトに入れない）。

## 6. 基本の編集（v0.1）

| 操作 | 内容 |
|---|---|
| なぞって消す | 消したい範囲をタイムライン上でマウスでなぞり、「消す」を押す |
| 並べ替え | 録画のかたまりをドラッグして順番を変える |
| 元に戻す・やり直す | すべての操作を何回でも戻せる |
| 再生 | プレビューで再生・一時停止。タイムラインを押すとその時刻へ移動 |
| タイムラインの拡大・縮小 | 細かい場所を直すときに広げる |
| つなぎ目のフェード（v0.5） | 録画と録画のつなぎ目は、普段はパッと切り替わる。つなぎ目を押すと「ふわっと切り替える」にできる |

## 7. 無音カット（v0.2）

- 「あなたの声」の音量が小さい時間が一定以上続く場所を、**切る候補**として見つける。
  - 仮の基準：0.5秒以上しゃべっていない場所。
- 候補はタイムラインに印で示す。候補の数と、切ると何分何秒短くなるかを表示する。
- **切る強さ**のつまみ（弱〜強）で、どのくらいの「間」から候補にするかを変えられる。
- 候補を押すと、その場所だけ残せる（もう一度押すと候補に戻る）。
- 「まとめて切る」で切る。切ったあとも「元に戻す」で戻せる。
- しゃべりの前後には少し余白を残す（仮：0.2秒）。言葉の頭や終わりが切れて不自然になるのを防ぐ。

## 8. 自動字幕（v0.3）

### 8.1 文字起こし

- 声を文字にする AI（Whisper 系の音声認識。MIT ライセンス）を、ブラウザの中で動かす。動画はネットに送らない。
- 最初の1回だけ、AI の部品（数百MB〜1GBほど）をダウンロードする。ダウンロードの前に大きさを知らせ、了承してもらう。
- グラフィックボードがあるパソコンでは、それを使って速く処理する。性能の低いパソコン向けに、時間はかかっても動く「軽いモード」を用意する。
- 長い録画では時間がかかるので、進み具合と残り時間の目安を出す。途中でやめても、続きから再開できる。
- 字幕の言語は、まず日本語だけ。

### 8.2 字幕の分け方

- 1行20文字まで、2行まで（仮）。
- 文の切れ目や読点（、）で分ける。言葉の途中では改行しない。
- 字幕が出る時間は、しゃべっている時間に合わせる。

### 8.3 字幕の直し方

- 画面の横に、字幕が時刻つきの文章で並ぶ（字幕の一覧）。
- 一覧の字幕を押すと、その場面へ移動する。そのまま文字を書き換えられる。
- 字幕を2つに分ける・ひとつにまとめることができる。
- 出る時間は、タイムライン上で字幕の端をドラッグして直せる。

### 8.4 見た目（テンプレート）

- 最初は「定番（白文字＋黒縁）」の1種類。
- 文字の色・大きさ・位置（下・上）を変えられる。
- フォントは、ソフトに入れて配ることが許されているもの（SIL Open Font License の日本語フォントなど）だけを使う。
- ほかの雰囲気のテンプレートは、使ってみて必要になったら足す。

### 8.5 .srt ファイル

- 字幕を YouTube の字幕機能で使えるファイル（.srt）として書き出せる。

## 9. 文章で編集（v0.4）

- 字幕の一覧で字幕を1行消すと、その部分の動画も消える。
- 消す前に、どこが消えるかをタイムラインで示す。「元に戻す」で戻せる。
- 最初は1行単位。日本語の音声認識は1文字ごとの時刻がずれやすいので、1文字単位で消す機能は試してから考える。

---

## 10. 画像・図形・演出

### 10.1 画像（v0.5）

- 読み込める形式：PNG、JPEG、WebP。
- 「右上」「右下」「左上」「左下」「中央」「画面いっぱい」から位置を選んで置く。必要ならドラッグで動かしたり大きさを変えたりできる。
- 出す時間は、タイムライン上で範囲をなぞって決める。

### 10.2 矢印・枠（v0.6）

- 矢印・四角い枠・丸の3種類から始める。
- 色と線の太さを変えられる。置き方は画像と同じ。

### 10.3 画面の一部を拡大（v0.6）

- プレビュー上で拡大したい範囲を四角で囲み、拡大する時間をタイムラインでなぞる。
- 寄るときと戻るときは自動でなめらかに動く（仮：0.3秒）。動きを細かく指定する必要はない。

### 10.4 速さを変える（v0.6）

- なぞった範囲を 0.5倍・2倍・4倍 から選んで変える。
- 速さを変えても、声の高さは変わらないようにする。
- 範囲内の字幕の時間も、速さに合わせて自動で直す。

## 11. 音

### 11.1 BGM（v0.5）

- ソフトに CC0 の曲を何曲か入れておく（曲数は仮：5曲くらい）。
  - 1曲ずつ「ソフトに入れて配ってよいか」を確かめ、入手先・作者・ライセンスを `public/THIRD_PARTY_LICENSES.txt` に記録する。
  - CC0 の曲でも、第三者が YouTube の著作権管理（Content ID）に登録していることがある。入れる前に、信頼できる入手先かを確かめる。
- 自分で用意した曲も読み込める。そのとき、他人の曲を勝手に使うと著作権の侵害になることを案内する。
- 動画の長さに合わせて曲をくり返す。始まりと終わりは自動でフェードする。
- しゃべっている間は、BGM の音量を自動で小さくする。

### 11.2 効果音（v0.5）

- 「ピコン」「ドン」「シュッ」などの短い音を、プログラムで自作して入れておく。
- 再生位置で押すと、その時刻に置ける。

### 11.3 声の仕上げ（v0.7）

- 声の大きさを、YouTube で聞きやすい大きさにそろえる。
- エアコンの音などの雑音を減らす。
- 「えー」「あのー」などの口ぐせを見つけて、切る候補にする。文字起こしの AI は口ぐせを省いてしまうことが多いので、うまく動くかは試して確かめる。だめなら別の方法を考える。

## 12. AI のお手伝い（v0.8）

### 12.1 やること

| やること | 使う方法 |
|---|---|
| 動画の内容の調べもの | A「AIに聞く」 |
| 台本の下書き（録画の前に話す流れを考える） | A「AIに聞く」 |
| 字幕の誤字直し | C ブラウザに入っている AI（使えなければ A） |
| タイトル・概要欄の文章の案 | C（使えなければ A） |
| チャプターの案 | C（使えなければ A） |

### 12.2 A「AIに聞く」

- テロッパが質問文（必要なら字幕の文章入り）を作ってコピーし、使う人が選んだ AI のサイトを新しいタブで開く。
- 貼り付け・送信・答えのコピーは**使う人が自分で行う**。テロッパが AI のサイトを自動で操作することはしない（各社の利用規約で禁止されているため）。
- 開く前に「この文章は○○の会社に送られます」と知らせる。
- AI のサービスのロゴは使わず、名前を文字で書くだけにする。
- AI サイトの答えを貼り戻す欄を用意する（例：チャプターの案を貼ると、タイムラインに反映できる）。

### 12.3 C ブラウザに入っている AI

- Chrome に入っている小さな AI（Gemini Nano、Prompt API など）を使う。パソコンの中で動き、ネットに送らない。
- 一部の機能はまだ試験中。作るときに、使えるかどうかと利用条件を確かめる。
- 性能の足りないパソコンや Edge では使えないことがある。そのときは自動で A の方法を案内する。
- Google の生成 AI の禁止事項ポリシーが使う人にも適用されるので、最初に一度案内する。
- 小さい AI なので、長い字幕は少しずつ区切って処理する。

### 12.4 共通のルール

- AI の答えは「提案」として見せる。採用するかは使う人が決める。
- 「AI は間違えることがあります。確かめてから使ってください」と添える。特に解説動画の内容（事実）は、使う人が確かめる前提にする。

## 13. チャプター・サムネイル

### 13.1 チャプター（v0.8）

- 字幕の内容から、YouTube の概要欄に貼る目次（`0:00 はじめに` の形）の案を作る。
- YouTube のチャプターのルール（最初は 0:00、3つ以上、それぞれ10秒以上）に合わせる。ルールは作るときに最新のものを確かめる。
- 書き出した動画の時刻（カット後）に合わせる。

### 13.2 サムネイル（v0.9）

- 動画の一場面を選び、大きな文字を載せて、YouTube のサムネイル用の画像（PNG、1280×720）を作る。
- 文字の見た目はテンプレートから選ぶ。

---

## 14. 書き出し（v0.1）

- 形式は MP4。
- 画質は3段階から選ぶ（数値は仮）。

| 画質 | 大きさ | 用途 |
|---|---|---|
| きれい（最初はこれ） | 1920×1080 | YouTube に上げる |
| ふつう | 1920×1080（ファイルを小さめに） | ファイルの大きさを抑えたい |
| 軽い | 1280×720 | 確認用・送る用 |

- なめらかさは元の録画に合わせる。録画ごとに違う場合は、一番長い録画に合わせる（仮）。
- 書き出しの前に、かかる時間とファイルの大きさの目安を出す。途中でやめられる。
- 書き出し中にタブを閉じようとしたら警告する。
- 動画の変換は、ブラウザに入っている機能（WebCodecs）を使う。
- YouTube への直接アップロードは作らない（Google の審査などが必要なため）。書き出したファイルを使う人がアップロードする。
- 書き出しが終わったら、YouTube にアップロードする手順と、チャプター・概要欄を貼る場所を案内する。

---

## 15. 保存

- **自動保存**：編集内容はブラウザの中に自動で保存する。タブを閉じても、次に開いたら続きから作業できる。
- **ファイルに保存**：念のため、編集内容をファイル（プロジェクトファイル、拡張子は仮に `.teroppa`）に保存できる。別のパソコンに移すときにも使う。
- どちらも保存するのは**編集内容だけ**。元の録画はコピーせず、場所だけを覚える。
  - 作業を再開するとき、ブラウザが録画を読むための許可をもう一度求めることがある。
  - 録画を移動・削除すると開けなくなる。そのときは「録画が見つかりません。場所を教えてください」と案内する。
- 自動字幕の結果も編集内容に含める（作り直さなくてよいように）。

---

## 16. 初めての人のための練習（v1.0）

- 初めて開いたとき、「見本の録画で練習する」を選べる。
- 見本の録画は自作する（しゃべり・画面ともに自作。権利の心配がないもの）。
- 手順の案内に沿って、読み込みから書き出しまで1本完成させる。
- 練習はとばしてもよい。あとからいつでもやり直せる。

## 17. キーボード操作

| キー | 動き |
|---|---|
| スペース | 再生・一時停止 |
| ← → | 1秒戻る・進む（Shift と一緒に押すと5秒） |
| Delete | なぞった範囲を消す |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+S | ファイルに保存 |
| ＋ / − | タイムラインの拡大・縮小 |
| ? | キーの一覧を表示 |

- 字幕を書き換えているあいだは、キーは文字の入力に使う（スペースを押しても再生しない）。

## 18. 技術方針

| 項目 | 内容 |
|---|---|
| 言語 | TypeScript |
| 開発ツール | Vite |
| 自動テスト | Vitest |
| 画面の確認 | Playwright（ヘッドレスブラウザ） |
| 動画の読み書き | ブラウザに入っている WebCodecs |
| MP4・MKV などの読み書き | ライブラリを使う（v0.1 で選ぶ。ライセンスを確かめる） |
| 画面の部品 | v0.1 で決める |
| 自動字幕 | Whisper 系の音声認識をブラウザで動かす（v0.3 で部品を選ぶ） |
| 保存 | ブラウザの保存領域（IndexedDB）と、ファイルの読み書きの機能 |
| 公開 | GitHub Pages か Cloudflare Pages（どちらも無料）。作りながら技術的に合うほうを選ぶ |

### 設計の原則

- **編集のルールと画面を分ける**：タイムラインの計算、無音の見つけ方、字幕の分け方などは、画面やブラウザの機能を使わずに動くように作る。自動テストで確かめられる。
- **元の録画は書き換えない**：編集内容は「どの録画の、どこからどこまでを、どう使うか」のデータとして持つ。元に戻す・保存・書き出しはこのデータから行う。
- **中身はデータで増やす**：字幕のテンプレート、BGM の一覧、効果音、画質の設定などは表（データ）で定義する。
- **重い処理で画面を止めない**：文字起こし・音の分析・書き出しは、画面とは別の作業場所（Web Worker）で行う。
- **長い録画でも必要な部分だけ読む**：3時間の録画を丸ごとメモリに入れない。

### フォルダ構成（案）

```
src/core/     編集のルール（画面・ブラウザに依存しない）
src/media/    動画・音の読み込み、分析、書き出し
src/ai/       自動字幕と AI のお手伝い
src/data/     テンプレート・BGM・効果音・画質などのデータ
src/ui/       画面表示と操作
tests/        自動テスト
docs/         仕様書などの文書
public/       BGM・フォントなどの素材とライセンス表記
```

## 20. 規約・法律・ライセンス

### 20.1 部品（ライブラリ）と特許

- 動画の圧縮方式（H.264 など）には特許が関わる。変換の部品を自分たちで配らず、ブラウザ（と OS）に入っている WebCodecs を使う。
- 使う部品は、ライセンスを1つずつ確かめてから選ぶ。ソースコードのライセンスは未定なので、**MIT と GPL のどちらを選んでも使える条件の部品**だけを使う。
- 部品を追加したら `public/THIRD_PARTY_LICENSES.txt` にライセンス表記を追記し、ソフトの中でも見られるようにする。
- AI の部品（音声認識のモデルなど）も、商用利用と再配布の条件を確かめてから使う。

### 20.2 同梱する素材

- BGM：CC0 の曲だけ。1曲ずつ入手先・作者・ライセンスを記録する（11.1）。
- 効果音・見本の録画：自作する。
- フォント：SIL Open Font License など、ソフトに入れて配ることが許されているものだけ。
- 字幕のテンプレートやアイコン：自作する。

### 20.3 まねしない

- 既存の動画編集ソフトの名前・ロゴ・アイコン・画面デザインはまねしない。
- 一般的な機能（タイムライン、字幕、無音カットなど）を作ることは問題ない。
- AI のサービス名は、案内のために文字で書くだけにする。ロゴは使わない。

### 20.4 AI サービスの利用規約

- ChatGPT・Claude・Gemini などのサイトを、プログラムで自動操作しない。人の代わりにソフトが操作することは、各社の利用規約で禁止されている。
- 「AIに聞く」は、使う人が自分でサイトを使う形にする（12.2）。
- ブラウザに入っている AI は、提供元の利用条件・禁止事項ポリシーに従う（12.3）。

### 20.5 使う人への案内

- 他人の音楽・動画・画像を勝手に使うと著作権の侵害になることを案内する。
- ゲーム実況では、ゲーム会社ごとに「動画を出してよいか」のルール（ガイドライン）があることを案内する。
- AI の答えは間違えることがあるので、確かめてから使うよう案内する。

### 20.6 個人情報

- アクセス解析（使われ方の記録）は取らない。
- 録画・字幕・編集内容は、使う人のパソコンの外に送らない。
- 外部と通信するのは、AI の部品のダウンロード（配布元のサイト。接続元の IP アドレスが相手に伝わる）や、使う人が自分で開く AI のサイトなど。
- 「どこに何が送られるか」を一覧にした説明ページを作る。日本の電気通信事業法の外部送信のルールが当てはまるかは、公開前に確かめる。

### 20.7 その他

- YouTube への直接アップロードは作らない（14）。
- 公開場所のサービスの利用規約（商用利用の制限、ファイルの大きさの上限など）を守る。
- リポジトリは公開されているので、API キーなどの秘密情報は入れない。
- ソースコードのライセンスは v1.0 の前に決める。それまでは、他の人はコードを見られるが、使ったり改造したりはできない。
- 公開前に、ソフトの名前が既存の商標・アプリ名と重複していないか確認する。
