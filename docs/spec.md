# テロッパ（仮）仕様書

> 仮の名前。公開前に、特許庁の商標検索（J-PlatPat）と既存のアプリ・サービス名で重複がないか確認する。

この文書は、これまでの相談で決まった内容をまとめたもの。数値（秒数、文字数、画質など）はすべて仮で、実際に使いながら調整する。

---

## 1. 概要

| 項目 | 内容 |
|---|---|
| 種類 | 動画編集ソフト |
| 主な対象 | YouTube の解説動画・ゲーム実況（横長、1人でしゃべる） |
| 動かす場所 | ブラウザ（Chrome と Edge の最新版）。インストール不要 |
| 読み込む録画の長さ | 3時間まで |
| 書き出す動画 | MP4、横長（16:9）。なめらかさ（1秒あたりのコマ数）は元の録画に合わせる |
| 料金 | 無料。ロゴの透かしも入れない |
| 開発で試すパソコン | 高性能な Windows PC（ゲーム用のグラフィックボードあり） |

### テロッパならではの特徴

1. **しゃべり動画の面倒な作業を自動にする**：「間」を見つけて切る（無音カット）、声を文字にする（自動字幕）。初心者が一番時間を取られる作業を、ボタンひとつにする。
2. **迷わない画面**：次にやることを、いつもひとつだけ大きく案内する。案内どおりに進めれば1本完成する。
3. **動画をネットに送らない**：読み込み・自動字幕・書き出しは、すべて使う人のパソコンの中で行う。
4. **無料・インストール不要・透かしなし**：ブラウザで開くだけで使える。

### 有料ソフトと比べた位置づけ

機能の数では有料ソフトに勝とうとしない。解説・実況で必要な作業に絞り、「速く、迷わずできる」ことで勝つ。

| 機能 | テロッパ |
|---|---|
| 録画をつなぐ・切る | ○（v0.1） |
| 無音カット | ○（v0.2） |
| 自動字幕 | ○（v0.3、無料・パソコンの中で処理） |
| 文章で編集 | ○（v0.4） |
| BGM・効果音（声の間は BGM を自動で小さく） | ○（v0.5） |
| 画面の一部を拡大・速さを変える・矢印や枠 | ○（v0.6） |
| 声の雑音を減らす・音量をそろえる | ○（v0.7） |
| 切り替え効果 | △ フェードだけ |
| 素材集（BGM・テンプレート） | △ 権利を確かめたものだけなので少なめ |
| 色の補正、動きをつけるアニメーション、背景の合成 | ×（解説・実況ではあまり使わず、初心者には難しい） |
| 顔出しの小窓（ワイプ）、縦長ショートへの作り直し | ×（あとで考える） |

## 2. 用語

画面の文言では専門用語を避ける。この表の「画面での言い方」を使う。

| 用語 | 画面での言い方 | 意味 |
|---|---|---|
| プロジェクト | 作品 | 1本の動画を作るための作業のまとまり |
| 録画 | 録画 | 読み込んだ動画ファイル |
| 素材 | 素材 | 録画・画像・BGM・効果音のこと |
| タイムライン | タイムライン | 画面下の横長の帯。動画・字幕・音が時間の順に並ぶ |
| 再生位置 | 再生位置 | いまプレビューに映っている時刻。タイムライン上の縦線 |
| クリップ | （見せない） | タイムラインに並んだ素材のひとかたまり |
| 声の音 | あなたの声 | 録画に入っている音のうち、しゃべっている人の声 |
| 無音カット | 「間」を切る | しゃべっていない部分を見つけて切ること |
| 候補 | 切る候補 | 自動で見つけた「切ったほうがよさそうな場所」。切る前に確かめられる |
| 字幕 | 字幕 | 画面に出す文字（テロップ） |
| テンプレート | 見た目 | 字幕やサムネイルの見た目のひな形 |
| 書き出し | 書き出し | 完成した1本の動画ファイルを作ること |

## 3. 画面

### 3.1 全体の形（案内つきタイムライン）

```
[①読み込み]→[②間カット]→[③字幕]→[④飾り]→[⑤音の仕上げ]→[⑥書き出し]   ← 手順の案内
──────────────────────────────────────────
                                      │ 字幕の一覧
        （ 動画のプレビュー ）          │ 0:12 今日はボス戦です
                                      │ 0:15 このボス、実は弱点が…
──────────────────────────────────────────
 「間」を自動で切りました（3分12秒 短くなりました）  ← いまやることの案内
    [ 結果を見る ]        [ 次へ ▶ ]
──────────────────────────────────────────
 動画 ■■■■ ■■■ ■■■■■■ ■■■                          ← タイムライン
 字幕   ▭▭  ▭▭▭   ▭▭  ▭▭▭
 BGM  ━━━━━━━━━━━━━━━━━━
```

- 上の**手順の案内**どおりに進めれば1本完成する。慣れた人は、下のタイムラインで自由に細かく直せる。
- 手順は版が上がるたびに増える。v0.1 は「読み込み → 書き出し」だけ。v0.5 で「飾り」「BGM・効果音」が入り、6つになった。v0.7 で「BGM・効果音」を「音の仕上げ」（声・BGM・効果音のタブ）にした。「間」を切る手順には「えー」「あのー」のタブがある。
- 横の幅が狭い画面では、手順の案内を上の帯の2段目に出す（手順の名前はいつも全部見せる）。
- 右側の字幕の一覧は、字幕ができてから出す（v0.3〜）。

### 3.2 迷わない画面の約束

- 次にやることを、いつもひとつだけ大きく見せる。
- 1画面に出すボタンを少なくする。使う場面でだけ出す。
- 専門用語を使わない（「トリミング」ではなく「切る」）。
- 自動でやったことは「提案」として見せ、気に入らなければ1回押すだけで戻せる。
- 「元に戻す」がいつでも使える。失敗を怖がらなくていい。
- ボタンにマウスを乗せると、短い説明と、使えるキーを出す。

### 3.3 見た目

- 暗い画面と明るい画面を切り替えられる。最初はパソコンの設定に合わせる。
- テーマ色は**オレンジ**。明るい画面では、文字が読みにくくならないよう濃いめのオレンジを使う。
- 既存の動画編集ソフトの画面デザイン・アイコン・ロゴはまねしない。

## 4. 編集の流れ

使う人がたどる流れ。すべての版がそろったときの形。

1. **読み込み**：録画を入れる（何本でも）。音が複数入っていたら「どれがあなたの声？」を選ぶ。
2. **「間」を切る**：無音カットの候補を確かめて、まとめて切る。
3. **字幕**：自動で文字起こし。間違いを一覧で直す。見た目を選ぶ。
4. **飾り**：画像・矢印や枠・拡大・速さの変更を入れる（使わなくてもよい）。
5. **BGM・効果音**：曲を選ぶと、声の間は自動で小さくなる。
6. **書き出し**：画質を選んで MP4 にする。字幕は .srt ファイルでも出せる。
7. **仕上げのお手伝い**：チャプター・タイトル・概要欄の案、サムネイル。

---

## 5. 読み込み

- 読み込める形式：MP4、MOV（iPhone など）、MKV（OBS でよく使う形式）、WebM。
- iPhone の新しい形式（HEVC）は、パソコンによっては読めないことがある。そのときは理由と対処を画面で案内する。
- 複数の録画を読み込むと、読み込んだ順にタイムラインに並ぶ。ドラッグで並べ替えられる。
- 元の録画ファイルは書き換えない。編集内容は「どの録画の、どこからどこまでを使うか」の記録として持つ。
- 録画を丸ごとメモリに読み込まず、必要な部分だけを読む。3時間の録画でも重くならないようにする。
- 読み込んだ録画の音の形（波形）を、裏側で作ってタイムラインに出す。しゃべっている場所の目安になる。一度作った波形はブラウザの中に残し、同じ録画なら作り直さない。
- 音が複数入っている録画は、はじめは1つ目の音だけを使う（OBS の「音声トラック1」は、ふつうすべての音をまとめたもの）。読み込んだときに「音の設定」を開いて、役割を選んでもらう（5.1）。

### 5.1 声を選ぶ（v0.2）

- OBS などでは「自分の声」と「ゲームの音」を別々の音として1つのファイルに保存できる。
- 録画に音が複数入っていたら、読み込んだときに「音の設定」を開き、聴き比べて「あなたの声」を選んでもらう。
  - 音ごとに「あなたの声」「ゲームの音など」「使わない」を選ぶ。「聴く」を押すと、その音の一番大きい6秒を聴ける。小さな波形も出す。
  - 「音の設定」は、入っている録画の一覧からいつでも開ける。
- 無音カットと自動字幕は、選んだ声の音だけを使う（ゲームの音にじゃまされず正確になる）。
- 声とゲームの音は、別々に音量を変えられる（0〜200%）。書き出しとプレビューでは、「使わない」以外の音を混ぜて鳴らす。
- 音がひとつしかない録画は、そのまま使う。
- OBS で声とゲームの音を分けて録る設定方法を、手順の案内として載せる（OBS 自体はソフトに入れない）。

## 6. 基本の編集（v0.1）

| 操作 | 内容 |
|---|---|
| なぞって消す | タイムラインの下の段を、消したい範囲だけマウスでなぞり、「消す」を押す |
| 並べ替え | かたまりの上の「名前の帯」をドラッグして順番を変える |
| 元に戻す・やり直す | すべての操作を何回でも戻せる |
| 再生 | プレビューで再生・一時停止。タイムラインを押すとその時刻へ移動 |
| タイムラインの拡大・縮小 | 細かい場所を直すときに広げる。Ctrl を押しながらホイールでも変えられる。「全体を表示」で元に戻る |
| つなぎ目のフェード（v0.5） | 録画と録画のつなぎ目は、普段はパッと切り替わる。つなぎ目を押すと「ふわっと切り替える」にできる |

## 7. 無音カット（v0.2）

- 「あなたの声」の音量が小さい時間が一定以上続く場所を、**切る候補**として見つける。
  - 仮の基準：0.5秒以上しゃべっていない場所。
  - 「しゃべっている」とみなす大きさは、録画ごとに静かな部分としゃべっている部分の大きさから決める（マイクの大きさが違っても同じように見つかる）。差がほとんどない録画では候補を出さない。
  - 0.1秒より短い物音は、しゃべりとみなさない。
- 候補はタイムラインに赤い印で示す。候補の数と、切ると何分何秒短くなるかを表示する。
- **切る強さ**を5段階（とても弱い〜とても強い）から選べる。どのくらいの「間」から候補にするか（1.5秒〜0.25秒）と、残す余白が変わる。
- 候補を押すと、その場所だけ残せる（もう一度押すと候補に戻る）。
- 「まとめて切る」で切る。切ったあとも「元に戻す」で戻せる。
- しゃべりの前後には少し余白を残す（仮：0.2秒）。言葉の頭や終わりが切れて不自然になるのを防ぐ。録画の最初と最後の「間」は、余白を残さずに切る。
- 候補は録画の中の時刻で見つけるので、並べ替えたあとでも、手で消したあとでも、残っている部分の「間」だけが出る。

## 8. 自動字幕（v0.3）

### 8.1 文字起こし

- 声を文字にする AI（Whisper 系の音声認識。MIT ライセンス）を、ブラウザの中で動かす。動画はネットに送らない。
  - 動かすのは Transformers.js（Apache-2.0）と ONNX Runtime Web（MIT）。
  - 標準：whisper-large-v3-turbo（グラフィックボードと16ビットの計算が要る。約1.4GB）。軽いモード：whisper-small（どのパソコンでも動く。約250MB）。パソコンに合うほうを最初に選んでおく。
- 最初の1回だけ、AI の部品（数百MB〜1.5GBほど）をダウンロードする。ダウンロードの前に、配布元に問い合わせた大きさを知らせ、了承してもらう（分からないときは目安を出す）。了承はブラウザの中に覚えておく。
- 「間」の調べの結果を使い、しゃべっている部分だけを28秒以内のまとまりにして AI に渡す（速く、聞き間違いも減る）。まだ字幕にしていない部分だけを字幕にするので、やめたあとも続きから作れる（済んだ範囲は作品に記録する）。
- グラフィックボードがあるパソコンでは、それを使って速く処理する。性能の低いパソコン向けに、時間はかかっても動く「軽いモード」を用意する。
- 長い録画では時間がかかるので、進み具合と残り時間の目安を出す。途中でやめても、続きから再開できる。
- 字幕の言語は、まず日本語だけ。

### 8.2 字幕の分け方

- 1行20文字まで、2行まで（仮）。
- 文の切れ目や読点（、）で分ける。言葉の途中では改行しない。
- 字幕が出る時間は、しゃべっている時間に合わせる。1つのまとまりを分けたときは、文字数に合わせて時間を分ける。
- 言葉の区切りは、ブラウザに入っている日本語の単語の区切りの機能（Intl.Segmenter）で調べる。句読点や助詞のあとで区切りやすくする。
- 字幕の終わりの「。」「、」は表示しない（「！」「？」は表示する）。
- 字幕は録画の中の時刻で持つ。「間」を切ったり並べ替えたりしても、映像とずれない。

### 8.3 字幕の直し方

- 画面の横に、字幕が時刻つきの文章で並ぶ（字幕の一覧）。
- 一覧の字幕を押すと、その場面へ移動する。そのまま文字を書き換えられる。
- 字幕を2つに分ける（文字を入れる位置で）・後ろの字幕とひとつにまとめる・字幕だけを消す・再生位置に字幕を足すことができる。1行の文字数を数えて、20文字を超えたら知らせる。
- 出る時間は、タイムラインの「字幕」の段で、字幕の端をドラッグして直せる。前後の字幕とは重ならない。

### 8.4 見た目（テンプレート）

- 最初は「定番（白文字＋黒縁）」の1種類。
- 文字の色・大きさ・位置（下・上）を変えられる。
- フォントは、ソフトに入れて配ることが許されているもの（SIL Open Font License の日本語フォントなど）だけを使う。
- ほかの雰囲気のテンプレートは、使ってみて必要になったら足す。

### 8.5 .srt ファイル

- 字幕を YouTube の字幕機能で使えるファイル（.srt）として書き出せる（完成した動画の時刻で）。
- ほかのソフトで作った字幕ファイル（.srt）も読み込める。
- 書き出しでは、字幕を動画に入れるかを選べる（入れない場合は .srt だけを使う）。

## 9. 文章で編集（v0.4）

- 字幕の一覧で字幕を1行消すと、その部分の動画も消える（行の「はさみ」のボタン）。字幕だけを消す（動画はそのまま）ボタンとは分ける。
- 消す前に、どこが消えるかをタイムラインに赤い印で示し、「消す」「やめる」を選んでもらう。「元に戻す」で戻せる。
- 消すのは、その字幕の時間（録画の中の時刻）。すでに一部がカットされている字幕でも、残っている部分を消す。
- 最初は1行単位。日本語の音声認識は1文字ごとの時刻がずれやすいので、1文字単位で消す機能は試してから考える。

## 10. 画像・図形・演出

### 10.1 画像（v0.5）

- 読み込める形式：PNG、JPEG、WebP（1枚 20MB まで）。
- 「右上」「右下」「左上」「左下」「中央」「画面いっぱい」から位置を選んで置く（最初は右上）。必要ならプレビューの上でドラッグして動かしたり、右下の角をドラッグして大きさを変えたりできる（縦横の比は保つ）。
  - 四隅は画面の幅の30%、中央は50%の大きさ。「画面いっぱい」は、画像の形を保ったまま画面に収める。
- 出す時間は、タイムライン上で範囲をなぞって決める（なぞらなければ、再生位置から5秒）。タイムラインの「画像」の段で、端をドラッグして変えられる。
- 出す時間は字幕と同じく録画の中の時刻で持つので、あとで「間」を切ったり並べ替えたりしても、同じ映像の上に出る。
- 画像は作品ファイルにも入れる（別のパソコンでも、作品ファイルだけで画像が出る）。

### 10.5 つなぎ目のフェード（v0.5）

- つなぎ目の前で画面を暗く・音を小さくし、後ろで元に戻す（片側0.4秒）。場面が変わったことが分かりやすくなる。
- 「間」を切ったつなぎ目すべてにフェードを入れると見づらいので、入れるつなぎ目は選ぶ：
  - 再生位置に一番近いつなぎ目に入れる・やめる。
  - 録画が切り替わるつなぎ目すべてにまとめて入れる。
  - 動画の始まり（最初のつなぎ目）と、動画の終わり（1秒）も選べる。
- フェードは録画の音だけにかける。BGM は止めずに続ける。
- フェードを入れたつなぎ目は、タイムラインにオレンジの印で示す。

### 10.6 飾りの手順の画面（v0.6）

- 「画像」「矢印・枠」「拡大」「速さ」「フェード」をタブで切り替える（1度に見せる操作を少なくする）。
- タイムラインの「画像」「矢印・枠」「拡大」の段を押すと、そのタブを開いて選んだ状態になる。

### 10.2 矢印・枠（v0.6）

- 矢印・四角い枠・丸の3種類から始める。
- 色（赤・黄・白・水色・黄緑）と線の太さ（細い・ふつう・太い）を変えられる。矢印は8つの向きから選ぶ。
- 置き方は画像と同じ：四隅と中央に置き直せて、プレビューの上でドラッグして動かし、右下の角で大きさを変えられる（縦横は別々に変えられる）。出す時間はタイムラインでなぞって決める。
- どんな映像の上でも見えるよう、黒いふちを付けて描く。

### 10.3 画面の一部を拡大（v0.6）

- 拡大する時間をタイムラインでなぞって「拡大を入れる」を押し、プレビューの点線の四角を動かして、大きく見せる場所を決める（四角は画面と同じ形。右下の角で大きさを変えられ、1.5倍・2倍・3倍もすぐ選べる。最大で約6倍）。
  - 場所を選んでいる間は、拡大する前の画面を見せる。
- 寄るときと戻るときは自動でなめらかに動く（0.3秒）。動きを細かく指定する必要はない。
- 拡大するのは録画の映像だけ。字幕・画像・矢印などは拡大しない。

### 10.4 速さを変える（v0.6）

- なぞった範囲を 0.5倍・2倍・4倍 から選んで変える。「元の速さ」で戻せる。
- 速さを変えても、声の高さは変わらないようにする（WSOLA という方法：音を30ミリ秒ずつのかけらに分け、波の形が自然につながる位置を探して重ねる。`src/core/stretch.ts`）。プレビューも書き出しも同じ方法を使う。
- 範囲内の字幕の時間も、速さに合わせて自動で直す（字幕・画像・効果音などは録画の中の時刻で持っているので、タイムラインの位置は速さから計算する）。
- タイムラインの名前の帯に「【2倍】」のように出す。

## 11. 音

### 11.1 BGM（v0.5）

- ソフトに CC0 の曲を何曲か入れておく（曲数は仮：5曲くらい）。
  - 1曲ずつ「ソフトに入れて配ってよいか」を確かめ、入手先・作者・ライセンスを `public/THIRD_PARTY_LICENSES.txt` に記録する。
  - CC0 の曲でも、第三者が YouTube の著作権管理（Content ID）に登録していることがある。入れる前に、信頼できる入手先かを確かめる。
  - **v0.5 の時点**：作業環境から CC0 の曲の入手先（OpenGameArt・Freesound・Free Music Archive など）につながらず、曲を確かめられないため、CC0 の曲はまだ入れていない。かわりに、テロッパのプログラムで作る自作の曲を5曲入れた（「明るい」「おだやか」「わくわく」「しっとり」「かっこいい」）。ほかの人の曲や音の素材は使っていないので、Content ID に引っかかる心配がない。
  - 自作の曲は、和音と並び（楽譜のデータ：`src/data/music.ts`）から、その場で音を作る（`src/core/music.ts`）。くり返しのつなぎ目がわからないように作る。
- 自分で用意した曲も読み込める（MP3・M4A・WAV・OGG・FLAC など。10分・40MB まで）。選ぶ前に、他人の曲を勝手に使うと著作権の侵害になることを案内し、「確かめた」を押してもらう。
- 動画の長さに合わせて曲をくり返す。始まり（1.5秒）と終わり（3秒）は自動でフェードする。
- しゃべっている間は、BGM の音量を自動で小さくする（ふだんの30%。しゃべり始める0.25秒前から小さくし、しゃべり終わって0.6秒で戻す。0.8秒より短い息つぎでは戻さない）。しゃべっているかは「間」を切るときと同じ、声の音の大きさで調べる。
- BGM の大きさは選べる（最初は35%）。曲は試しに聴ける。

### 11.2 効果音（v0.5）

- 「ピコン」「ドン」「シュッ」などの短い音を、プログラムで自作して入れておく（v0.5：ピコン・ドン・シュッ・キラーン・ブブー・ポン の6種類。`src/core/sfx.ts`）。
- 再生位置で押すと、その時刻に置ける。録画の中の時刻で持つので、カットしてもずれない（置いた場所を切ると鳴らなくなる）。
- 効果音の大きさはまとめて変えられる。試しに聴ける。

### 11.3 声の仕上げ（v0.7）

- 声の大きさを、YouTube で聞きやすい大きさにそろえる。
  - 声の音の大きさを ITU-R BS.1770 の方法（K 特性・ゲートつきの統合ラウドネス、LUFS）で測る。録画の音を調べるときに一緒に測る（`src/core/features.ts`・`src/core/loudness.ts`）。
  - 「声の大きさをそろえる」を押すと、録画ごとに声を -16 LUFS にする倍率を「声の大きさ」に入れる（±12dB まで。元に戻せる）。BGM やゲームの音を足すと、YouTube の基準（-14 LUFS くらい）に近くなる。
  - 大きすぎる音は、音が割れないように自動でなめらかに抑える（上限 -1dBFS。5ミリ秒先を見て小さくし、0.12秒で戻す。`src/core/limiter.ts`）。プレビューはブラウザのコンプレッサーで同じように抑える。
- エアコンの音などの雑音を減らす。
  - 「弱く」「強く」から選ぶ。しゃべっていない静かな部分（合計8秒まで）から雑音の音色を調べ、作品に記録する（同じ設定で書き出せるように）。
  - 音を約21ミリ秒のかけらに分け、高さごとに雑音の分だけ小さくする（スペクトルの引き算。小さくしすぎず、時間と高さの両方でならして、ちりちりした音を出にくくする。`src/core/denoise.ts`）。声の音だけにかける。
- 「えー」「あのー」などの口ぐせを見つけて、切る候補にする。文字起こしの AI は口ぐせを省いてしまうことが多いので、うまく動くかは試して確かめる。だめなら別の方法を考える。
  - v0.7 では2つの方法で候補を出す（試験的。「間」を切る手順の「えー」「あのー」のタブ）：
    1. 字幕の行が口ぐせだけ（「えー」「えっと、あのー」など）のとき、その行の時間。
    2. 音：前後に「間」がある 0.3〜1.6 秒の短い声で、音色の変わり方がその人のふだんのしゃべりの半分以下（同じ音をのばしている）のもの。
  - 作業環境ではプログラムで作った音でしか確かめられていない。本物の声でどれくらい当たるかは、使う人の録画で確かめる（21 に記録）。まちがえることがあるので、候補を見せて、確かめてから切ってもらう。

## 12. AI のお手伝い（v0.8）

### 12.1 やること

| やること | 使う方法 |
|---|---|
| 動画の内容の調べもの | A「AIに聞く」 |
| 台本の下書き（録画の前に話す流れを考える） | A「AIに聞く」 |
| 字幕の誤字直し | C ブラウザに入っている AI（使えなければ A） |
| タイトル・概要欄の文章の案 | C（使えなければ A） |
| チャプターの案 | C（使えなければ A） |

### 12.2 A「AIに聞く」

- テロッパが質問文（必要なら字幕の文章入り）を作ってコピーし、使う人が選んだ AI のサイトを新しいタブで開く。
- 貼り付け・送信・答えのコピーは**使う人が自分で行う**。テロッパが AI のサイトを自動で操作することはしない（各社の利用規約で禁止されているため）。
- 開く前に「この文章は○○の会社に送られます」と知らせる。
- AI のサービスのロゴは使わず、名前を文字で書くだけにする。
- AI サイトの答えを貼り戻す欄を用意する（例：チャプターの案を貼ると、タイムラインに反映できる）。
- v0.8 で開けるサイト：ChatGPT（OpenAI）・Claude（Anthropic）・Gemini（Google）・Microsoft Copilot（Microsoft）。質問文はクリップボードにコピーし、サイトのトップページを新しいタブで開くだけ（URL に質問文を入れて送ることもしない）。質問文は開く前に画面に出し、使う人が直せる。
- 「AIに聞く」は上の帯のボタン（調べもの・台本の下書き）、字幕の手順の「AI で誤字を直す」、公開の準備の手順（タイトル・概要欄・チャプター）から使える。

### 12.3 C ブラウザに入っている AI

- Chrome に入っている小さな AI（Gemini Nano、Prompt API など）を使う。パソコンの中で動き、ネットに送らない。
- 一部の機能はまだ試験中。作るときに、使えるかどうかと利用条件を確かめる。
  - 2026年10月に確かめたこと：Prompt API（`LanguageModel`）は Chrome 148 からふつうのページでも使える。日本語の入力と出力に対応。Windows・macOS・Linux・Chromebook Plus のパソコンで、空き容量 22GB 以上、GPU（4GB より多い）か、メモリ 16GB 以上・4コア以上が要る。はじめて使うときに Chrome が AI の部品をダウンロードする。
  - テロッパは `LanguageModel.availability()` で使えるかを調べ、使えるときだけ「このパソコンの AI」ボタンを出す。
- 性能の足りないパソコンや Edge では使えないことがある。そのときは自動で A の方法を案内する。
- Google の生成 AI の禁止事項ポリシーが使う人にも適用されるので、最初に一度案内する。
- 小さい AI なので、長い字幕は少しずつ区切って処理する（誤字直しは15行ずつ、タイトルの案は1500文字ずつ要点をまとめてから、チャプターは動画を同じくらいの長さ（2分くらい・3〜12個）に区切って見出しを付ける）。
- 作業環境の Chrome には Prompt API がないので、画面の通しの確認では決まった答えを返す「まねした AI」で、テロッパ側の動き（案内・進み具合・答えの使い方）だけを確かめている。本物の Gemini Nano の答えの質は、使う人のパソコンで確かめる（21 に記録）。

### 12.4 共通のルール

- AI の答えは「提案」として見せる。採用するかは使う人が決める。
- 「AI は間違えることがあります。確かめてから使ってください」と添える。特に解説動画の内容（事実）は、使う人が確かめる前提にする。

## 13. チャプター・サムネイル

### 13.1 チャプター（v0.8）

- 字幕の内容から、YouTube の概要欄に貼る目次（`0:00 はじめに` の形）の案を作る。
- YouTube のチャプターのルール（最初は 0:00、3つ以上、それぞれ10秒以上）に合わせる。ルールは作るときに最新のものを確かめる。
  - 2026年10月に YouTube ヘルプで確かめたルール：最初は 0:00、3つ以上、時刻の順、それぞれ10秒以上。
  - AI の案は「ルールに合わせて直す」（時刻の順に並べる・最初を 0:00 にする・10秒より短いものをまとめる・動画の長さを超えるものを除く）。直したことは画面で知らせる。それでも合わないとき（3つに足りない・動画が短すぎる）は、そう知らせる。
- 書き出した動画の時刻（カット後）に合わせる。1時間を超える動画は `1:02:03` の形にする。
- チャプターは一覧で直せる（時刻・見出し・足す・消す）。タイムラインの「チャプター」の段にも出す。
- タイトル・概要欄・チャプターは作品に保存する。「概要欄をコピー」では、概要欄の文章とチャプターをまとめてコピーできる。

### 13.2 サムネイル（v0.9）

- 動画の一場面を選び、大きな文字を載せて、YouTube のサムネイル用の画像（PNG、1280×720）を作る。
- 文字の見た目はテンプレートから選ぶ。
- v0.9 で作ったもの（「公開の準備」の手順の「サムネイル」のタブ）：
  - 場面は、いまの再生位置から選ぶ（録画の中の時刻で持つので、カットしても同じ場面）。選び直すときは、サムネイルを隠して録画を見せる。
  - 文字は3行まで。最初はタイトルの文字。長い行は画面に収まるように小さくする。字幕と同じ Noto Sans JP。
  - 見た目（自作のテンプレート）：「インパクト」（太い黒ふちの大きな文字）・「ポップ」（白い文字に色のふち）・「帯」（暗い帯の上に文字）・「シンプル」（画面を少し暗くして白い文字）。色・大きさ（中・大・特大）・位置（上・真ん中・下）・そろえ方（左寄せ・中央）を選べる。
  - 作っている間は、プレビューにサムネイルを重ねて見せる。
  - 保存は 1280×720（ふつう）か 1920×1080、PNG か JPEG。YouTube ヘルプ（2026年10月に確かめた）では、16:9 で、スマホのアプリから上げるときは 2MB まで（パソコンからはもっと大きくてよい）。2MB を超えたら、そう知らせて JPEG をすすめる。
  - サムネイルも YouTube のコミュニティ ガイドラインの対象であることを案内する。

## 14. 書き出し（v0.1）

- 形式は MP4。
- 画質は3段階から選ぶ（数値は仮）。

| 画質 | 大きさ | 映像のビットレート（30コマ以下 / それより多い） | 音 | 用途 |
|---|---|---|---|---|
| きれい（最初はこれ） | 1920×1080 | 10Mbps / 15Mbps | 192kbps | YouTube に上げる |
| ふつう | 1920×1080 | 5Mbps / 8Mbps | 128kbps | ファイルの大きさを抑えたい |
| 軽い | 1280×720 | 2.5Mbps / 4Mbps | 128kbps | 確認用・送る用 |

- 縦長など 16:9 でない録画は、上下か左右に黒い帯をつけて収める。
- 音は 48kHz・ステレオにそろえる（録画ごとにサンプリングレートやチャンネル数が違ってもよい）。音が入っていない録画の部分は無音にする。
- 形式は H.264（映像）と AAC（音）を使う。パソコンのブラウザがこれらで書き出せないときは、VP9 か AV1（映像）と Opus（音）に切り替え、その旨を画面で知らせる。どれも MP4 に入れられ、YouTube にそのまま上げられる。

- なめらかさは元の録画に合わせる。録画ごとに違う場合は、タイムラインで一番長く使われている録画に合わせる（仮）。コマの間隔がばらばらな録画（スマホなど）も、一定の間隔にそろえる。
- 書き出しの前に、ファイルの大きさの目安を出す。かかる時間は、前回の書き出しの速さから目安を出す（初めてのときは、書き出しを始めてから残り時間を出す）。
- 途中でやめられる。やめたときは、途中までのファイルを残さない。
- 書き出し中にタブを閉じようとしたら警告する。
- 動画の変換は、ブラウザに入っている機能（WebCodecs）を使う。
- YouTube への直接アップロードは作らない（Google の審査などが必要なため）。書き出したファイルを使う人がアップロードする。
- 書き出しが終わったら、YouTube にアップロードする手順と、チャプター・概要欄を貼る場所を案内する。

## 15. 保存

- **自動保存**：編集内容はブラウザの中に自動で保存する。タブを閉じても、次に開いたら続きから作業できる。
- **ファイルに保存**：念のため、編集内容をファイル（作品ファイル、拡張子は `.teroppa`）に保存できる。別のパソコンに移すときにも使う。中身は文字（JSON）で、形式の名前と版の番号を入れておき、新しい版で保存したファイルを古い版で開こうとしたら知らせる。
- 作品ファイルを開いたときは、使っていた録画を選び直してもらう。名前と大きさが同じ録画は自動で当てはめる。
- どちらも保存するのは**編集内容だけ**。元の録画はコピーせず、場所だけを覚える。
  - 作業を再開するとき、ブラウザが録画を読むための許可をもう一度求めることがある。
  - 録画を移動・削除すると開けなくなる。そのときは「録画が見つかりません。場所を教えてください」と案内する。
- 自動字幕の結果も編集内容に含める（作り直さなくてよいように）。
- 作品に入れた画像と自分で用意した曲は、録画と違って小さいので、中身ごと保存する（自動保存はブラウザの中、作品ファイルには文字（base64）にして入れる）。同じファイルは中身の手がかり（SHA-256）で見分け、1つだけ持つ。使わなくなったものは、次に開いたときに消す。

## 16. 初めての人のための練習（v1.0）

- 初めて開いたとき、「見本の録画で練習する」を選べる。
- 見本の録画は自作する（しゃべり・画面ともに自作。権利の心配がないもの）。
- 手順の案内に沿って、読み込みから書き出しまで1本完成させる。
- 練習はとばしてもよい。あとからいつでもやり直せる。
- v1.0 で作ったもの：
  - 見本の録画（約46秒）は、テロッパがその場でプログラムで作る（画面：空と地面・主人公の青い丸・ボス・コインなどのゲームのような絵。音：しゃべっているように聞こえる音・「えー」のような声・部屋の雑音・「間」）。一度作ったらブラウザの中の保存場所（OPFS）に残し、2回目からはすぐ使う。録画のファイルはリポジトリに入れない。
  - 見本の声は本物のことばではないので、自動字幕では文字にならない。練習用の字幕（まちがいを2か所入れたもの）を「見本の字幕を入れる（練習用）」で入れられる。
  - 練習の間は、手順ごとに「やってみること」の案内を出す。「練習をやめる」で消せる。
  - 「録画を選ぶ」の画面と、「このソフトについて」から始められる。
  - 本物の声の見本（作者が自分で録ったもの）に差しかえることもできる（21 に記録）。

## 18. 技術方針

| 項目 | 内容 |
|---|---|
| 言語 | TypeScript |
| 開発ツール | Vite |
| 自動テスト | Vitest |
| 画面の確認 | Playwright（ヘッドレスブラウザ） |
| 動画の読み書き | ブラウザに入っている WebCodecs |
| MP4・MKV などの読み書き | Mediabunny（MPL-2.0）。WebCodecs を使って読み書きする |
| 画面の部品 | Preact（MIT） |
| 自動字幕 | Whisper 系の音声認識をブラウザで動かす（v0.3 で部品を選ぶ） |
| 保存 | ブラウザの保存領域（IndexedDB）と、ファイルの読み書きの機能（File System Access API） |
| 公開 | GitHub Pages か Cloudflare Pages（どちらも無料）。作りながら技術的に合うほうを選ぶ。v1.0 の時点：Cloudflare Pages は1ファイル 25MiB までで、自動字幕の部品（約25.6MiB）が置けないため、GitHub Pages が合う（`docs/release.md`） |

### 設計の原則

- **編集のルールと画面を分ける**：タイムラインの計算、無音の見つけ方、字幕の分け方などは、画面やブラウザの機能を使わずに動くように作る。自動テストで確かめられる。
- **元の録画は書き換えない**：編集内容は「どの録画の、どこからどこまでを、どう使うか」のデータとして持つ。元に戻す・保存・書き出しはこのデータから行う。
- **中身はデータで増やす**：字幕のテンプレート、BGM の一覧、効果音、画質の設定などは表（データ）で定義する。
- **重い処理で画面を止めない**：文字起こし・音の分析・書き出しは、画面とは別の作業場所（Web Worker）で行う。
- **長い録画でも必要な部分だけ読む**：3時間の録画を丸ごとメモリに入れない。

### フォルダ構成（案）

```
src/core/     編集のルール（画面・ブラウザに依存しない）
src/media/    動画・音の読み込み、分析、書き出し
src/ai/       自動字幕と AI のお手伝い
src/data/     テンプレート・BGM・効果音・画質などのデータ
src/ui/       画面表示と操作
tests/        自動テスト
docs/         仕様書などの文書
public/       BGM・フォントなどの素材とライセンス表記
```

## 19. 開発の順番

どの段階でも使える状態を保ちながら、少しずつ機能を足す。手順の案内は、どの版でも新しい機能に合わせて育てる。

v0.1 では、3時間の録画（1280×720、30コマ）で次のことを確かめた（作業用のヘッドレス Chromium。グラフィックボードなし）：調べるのに約0.2秒、好きな場所へ移動して映像が出るまで約0.1秒、波形ができるまで約50秒（裏側で作るので、その間も操作できる）、使うメモリ（JavaScript）は約35MB。

v1.0 の候補（1.0.0-rc.1）でも同じ録画で確かめた：読み込み約0.3秒、移動して映像が出るまで0.06〜0.15秒（音を調べている途中でも）、音の調べ（波形・声の大きさ・音色）約70秒、「間」の候補（2699か所）約0.2秒、口ぐせの候補約0.7秒、声の大きさの表示（-11.8 LUFS）、雑音の音色を調べる約0.3秒、雑音を減らしながらの再生、使うメモリ（JavaScript）約19MB。

## 20. 規約・法律・ライセンス

### 20.1 部品（ライブラリ）と特許

- 動画の圧縮方式（H.264 など）には特許が関わる。変換の部品を自分たちで配らず、ブラウザ（と OS）に入っている WebCodecs を使う。
- テロッパのソースコードは **MIT License**（v1.0 で決めた。リポジトリの `LICENSE`）。
- 使う部品は、ライセンスを1つずつ確かめてから選ぶ。**MIT のソフトに入れて配れる条件の部品**（MIT・BSD・Apache-2.0・MPL-2.0 など）だけを使う。GPL のように、テロッパ全体の条件を変えてしまう部品は使わない。
  - Mediabunny の MPL-2.0 は、ファイルごとに条件がかかる形のライセンス。Mediabunny のファイルを書き換えなければ、テロッパ全体を MIT にできる。書き換えた場合は、そのファイルを MPL-2.0 で公開する。
  - Apache-2.0（Transformers.js・@huggingface/tokenizers）は、ライセンス表記を添えれば MIT のソフトに入れて配れる。
- 部品を追加したら `public/THIRD_PARTY_LICENSES.txt` にライセンス表記を追記する。ソフトの中では「このソフトについて」から見られる。
- AI の部品（音声認識のモデルなど）も、商用利用と再配布の条件を確かめてから使う。

### 20.2 同梱する素材

- BGM：CC0 の曲だけ。1曲ずつ入手先・作者・ライセンスを記録する（11.1）。CC0 の曲が入るまでは、テロッパのプログラムで作る自作の曲を入れる。
- 効果音・見本の録画：自作する。
- 自作の BGM・効果音・見本の録画（絵と音）・テンプレートの見た目は **CC0 1.0**（v1.0 で決めた）。使う人は、作った動画やサムネイルに、クレジットなしで自由に使える（収益化した動画にも）。
- フォント：SIL Open Font License など、ソフトに入れて配ることが許されているものだけ。
- 字幕のテンプレートやアイコン：自作する。

### 20.3 まねしない

- 既存の動画編集ソフトの名前・ロゴ・アイコン・画面デザインはまねしない。
- 一般的な機能（タイムライン、字幕、無音カットなど）を作ることは問題ない。
- AI のサービス名は、案内のために文字で書くだけにする。ロゴは使わない。

### 20.4 AI サービスの利用規約

- ChatGPT・Claude・Gemini などのサイトを、プログラムで自動操作しない。人の代わりにソフトが操作することは、各社の利用規約で禁止されている。
- 「AIに聞く」は、使う人が自分でサイトを使う形にする（12.2）。
- ブラウザに入っている AI は、提供元の利用条件・禁止事項ポリシーに従う（12.3）。

### 20.5 使う人への案内

- 他人の音楽・動画・画像を勝手に使うと著作権の侵害になることを案内する。
- ゲーム実況では、ゲーム会社ごとに「動画を出してよいか」のルール（ガイドライン）があることを案内する。
- AI の答えは間違えることがあるので、確かめてから使うよう案内する。

- 外部と通信するのは、AI の部品のダウンロード（配布元のサイト。接続元の IP アドレスが相手に伝わる）や、使う人が自分で開く AI のサイトなど。
