# 公開の準備（v1.0）

テロッパを公開する前に、**使う人（作者）が決めること**と、**本物のパソコンで確かめること**の一覧です。
作業環境（クラウドの中のヘッドレス Chromium）では確かめられないものも、ここにまとめています。

## 1. 作者が決めること

| こと | いまの状態 | 決めるときの注意 |
|---|---|---|
| ソースコードのライセンス | 未定（決まるまでは、コードを見ることはできても、使ったり改造したりはできない） | 使っている部品は MIT と GPL のどちらでも使える条件にしてある。ただし Transformers.js・@huggingface/tokenizers の Apache-2.0 は GPL の **v3** とは一緒に使えるが v2 とは使えないので、GPL にするなら GPL-3.0 にする。決めたら `LICENSE` ファイルを足し、README と `docs/spec.md` の 20.7 を直す |
| 自作の BGM・効果音・見本の録画・テンプレートのライセンス | 未定（「テロッパで作った動画に使える」とだけ案内している） | ソースコードと同じにするか、CC0 などにするかを決める。動画に使う人が困らない条件にする |
| 正式な名前 | 「テロッパ（仮）」 | 既存の商標・アプリ名と重ならないか調べる（特許庁の [J-PlatPat](https://www.j-platpat.inpit.go.jp/) の商標検索、アプリストア、ウェブ検索）。決めたら画面・README・`package.json` の `name` を直す |
| 公開場所 | 未定 | 下の「2. 公開場所」を参照 |
| 入っている BGM | 自作の5曲（CC0 の曲の入手先に作業環境からつながらなかったため） | このままにするか、CC0 の曲を入れるかを決める。CC0 の曲を入れるときは、1曲ずつ入手先・作者・ライセンスを `public/THIRD_PARTY_LICENSES.txt` に書き、Content ID に登録されていない、信頼できる入手先かを確かめる |

## 2. 公開場所

ビルドした `dist/` は、ふつうのファイルだけのサイト（約33MB・133ファイル）なので、どちらの無料サービスにも置ける形です。2026年10月に、それぞれの公式の説明で確かめたこと：

| | GitHub Pages | Cloudflare Pages |
|---|---|---|
| 1つのファイルの大きさ | 決まった上限の記載なし（サイト全体で 1GB まで） | **25MiB まで** |
| テロッパで一番大きいファイル | 自動字幕の部品 `ort-wasm-simd-threaded.asyncify-*.wasm`（約25.6MiB） | ← このままでは置けない（別の場所に置く工夫が要る） |
| 転送量 | 月 100GB の目安（超えるとメールが来ることがある） | 無料プランでも目安の上限なし |
| 使い方の条件 | 商売のためのサイト（ネットショップ・有料のサービス）には使えない。無料のソフトの公開や、寄付のリンクはよい | 利用規約に従う |

- テロッパは無料のソフトなので、**GitHub Pages が技術的に合う**（ファイルの大きさの点）。
- 公開するときは、リポジトリの「Settings → Pages」で GitHub Actions から公開する設定にし、`npm run build` の `dist/` を公開する流れ（ワークフロー）を足す。テロッパは `vite.config.ts` の `base: './'` なので、どの場所（`https://〇〇.github.io/リポジトリ名/`）でも動く。
- 公開場所が決まったら、「外部に送る情報の一覧」（`src/data/external.ts` の1つ目）と `docs/spec.md` の 20.6 に、運営会社の名前を書く（GitHub, Inc.・アメリカ など）。

## 3. 本物の Chrome・Edge で確かめること

作業環境では確かめられなかったもの：

- [ ] 自動字幕：AI の部品のダウンロード（huggingface.co）と、文字起こしの正しさ・速さ（ふつうのモードと軽いモード）
- [ ] パソコンの中の AI（Chrome 148 以降の Prompt API・Gemini Nano）：案内・ダウンロード・誤字直し・タイトル・チャプターの答えの質
- [ ] H.264・AAC での書き出し（作業環境は VP9・Opus でだけ確かめた）と、YouTube に上げて再生できるか
- [ ] 本物の声の録画で：「間」の見つけ方、口ぐせの候補（試験的）、雑音を減らす、声の大きさをそろえる
- [ ] 3時間の録画の書き出し（作業環境では、3時間の録画から30秒を書き出すところまで）
- [ ] Edge でも同じように動くか
- [ ] 普通のノートPCで「軽いモード」が実用的な速さか

## 4. 法律・規約の確認

- [ ] 電気通信事業法の外部送信規律が当てはまるか（総務省の[外部送信規律の案内](https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu.html)を見る）。当てはまるかどうかにかかわらず、テロッパは画面の「このソフトについて → 外部に送る情報の一覧」で、送る情報・送り先・目的を出している。
- [ ] 公開場所のサービスの利用規約
- [ ] 正式な名前の商標の確認（上の 1）
- [ ] `public/THIRD_PARTY_LICENSES.txt` が、使っている部品・フォントのすべてを含んでいるか（部品を足したら必ず追記する）
